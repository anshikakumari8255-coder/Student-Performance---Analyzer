# Student Performance Analyzer

## Project Overview

Student Performance Analyzer is a Python-based application designed to store, analyze, and visualize student academic performance.

The system allows users to enter student details, marks, and attendance. It automatically calculates total marks, average, percentage, grade, result, highest and lowest performing subjects, and attendance status.

The project also provides student search, performance reports, and graphical visualization.

## Features

- Add student details
- Enter marks for five subjects
- Calculate total marks
- Calculate average marks
- Calculate percentage
- Calculate grade
- Check pass/fail result
- Find highest and lowest subject
- Check attendance eligibility
- View saved student records
- Search students using roll number
- Generate individual performance reports
- Calculate class average
- Display individual performance graphs
- Compare percentage of all students

## Technologies Used

- Python
- CSV file handling
- Matplotlib
- Object-Oriented Programming
- VS Code
