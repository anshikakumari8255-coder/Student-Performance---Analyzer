# Project Statement

## Project Title

Student Performance Analyzer

## Problem Statement

Managing and analyzing student academic performance manually can be time-consuming and may lead to calculation errors.

Teachers and students need a simple system that can store student information, marks, attendance, and automatically analyze academic performance.

The Student Performance Analyzer solves this problem by providing a Python-based system that stores student records and automatically calculates important performance indicators such as total marks, average, percentage, grade, result, highest subject, lowest subject, and attendance status.

## Scope of the Project

The project focuses on managing and analyzing academic performance of students.

The system can:

- Store student details
- Store marks for different subjects
- Calculate total and average marks
- Calculate percentage and grade
- Determine pass or fail status
- Analyze highest and lowest performing subjects
- Check attendance eligibility
- Search student records
- Generate student performance reports
- Calculate class average
- Display performance graphs

## Target Users

The main users of the system are:

- Students
- Teachers
- Academic staff

## High-Level Features

1. Student Management
   - Add student details
   - Store student records
   - Search students using roll number

2. Marks Management
   - Enter subject-wise marks
   - Validate marks
   - Calculate total and average

3. Performance Analysis
   - Calculate percentage
   - Assign grades
   - Determine pass/fail result
   - Find highest and lowest subjects
   - Calculate class average

4. Attendance Analysis
   - Store attendance percentage
   - Check attendance eligibility

5. Report Generation
   - Generate individual student performance reports

6. Data Visualization
   - Display subject-wise marks graph
   - Compare percentages of multiple students

## Technologies Used

- Python
- CSV
- Matplotlib
- Object-Oriented Programming
- VS Code

## Project Objectives

The main objectives of the Student Performance Analyzer are:

- To reduce manual calculation of student marks and percentages.
- To provide accurate academic performance analysis.
- To identify the highest and lowest performing subjects.
- To analyze attendance eligibility.
- To provide visual representations of student performance.
- To maintain student records using CSV file handling.
- To provide a simple and user-friendly academic analysis system.
